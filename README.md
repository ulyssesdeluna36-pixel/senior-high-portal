# senior-high-portal
Senior High School Learning Management Portal built with HTML, CSS, and JavaScript for learning resources, assessments, and online exams.
## Senior High Learning Portal

This project is a web-based learning management system designed for Senior High School education. 
It provides a centralized platform for learning resources, performance assessments, periodical exams, 
teaching guides, and budget of work across all Senior High School subjects.

### Features
- Learning resources for Senior High School strands (STEM, ABM, HUMSS, GAS)
- Online quizzes and exams with automatic checking
- Teaching guides and lesson support for educators
- Budget of Work for organized curriculum planning
- Clean, professional, and user-friendly interface
- Built using pure HTML, CSS, and JavaScript (no frameworks)

### Purpose
This website aims to support teachers and students by providing an accessible digital platform 
for learning, assessment, and academic management in Senior High School.

### Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
